# P3 3.1 受限令牌错误确认

**日期：** 2026-08-12

## 初步判断

当前失败不是 PowerShell 命令格式问题，也不是虚拟环境没有激活。

`packages/platform/windows/isolation.py` 引用了：

```python
wintypes.LUID_AND_ATTRIBUTES
```

但 Python 的 `ctypes.wintypes` 没有提供这个结构体，因此受限令牌初始化在调用 Win32 API 前就失败，并按照设计 fail-closed。
