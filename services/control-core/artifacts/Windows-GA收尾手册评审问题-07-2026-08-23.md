# Windows GA 收尾手册评审问题 07

- 日期：2026 年 8 月 23 日
- 发布定位：Personal/Internal GA，仅本人使用

## 已确认决定

- 允许在明确命名的临时测试 VM 内导入自签代码签名证书。
- 禁止修改宿主机现有受信任证书存储、安全配置和用户配置。
- 验收结束后删除临时 VM，证书随 VM 一并清理。

## 当前待确认事项

Windows 10 22H2 与 Windows 11 的干净系统安装、升级、卸载、离线 WebView2 和回退验证需要可追溯的安装介质。若本机没有合适 ISO，Zcode 需要从 Microsoft 官方来源下载，并记录来源、文件名、大小和 SHA-256。

## 唯一确认问题

是否允许 Zcode 从 Microsoft 官方来源下载 Windows 10 22H2 和 Windows 11 ISO，仅用于临时 Hyper-V 验收？

推荐：**允许。只接受 Microsoft 官方来源；下载后记录 SHA-256；ISO 只挂载到临时测试 VM，不修改宿主机启动项；删除 ISO 前另行列出文件绝对路径、大小和验收证据供你确认。**

## 用户决定

- 决定：**允许**。
- 约束：只允许 Microsoft 官方来源；下载后记录来源、文件名、大小和 SHA-256。
- 使用范围：ISO 仅用于明确命名的临时 Hyper-V VM，不修改宿主机启动项。
- 清理：删除 ISO 前必须列出绝对路径、大小和关联验收证据，再单独确认。
