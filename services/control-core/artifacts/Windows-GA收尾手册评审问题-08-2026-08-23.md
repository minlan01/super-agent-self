# Windows GA 收尾手册评审问题 08

- 日期：2026 年 8 月 23 日
- 发布定位：Personal/Internal GA，仅本人使用

## 已确认决定

- 允许从 Microsoft 官方来源下载 Windows 10 22H2 与 Windows 11 ISO。
- ISO 只用于明确命名的临时 Hyper-V VM，并记录来源、大小和 SHA-256。
- ISO 删除前必须再次确认绝对路径和关联验收证据。

## 当前待确认事项

原手册包含登录、双账户审批、SmartScreen、UAC、安全桌面、`Win+L` 锁定/解锁以及私钥密码等交互。普通应用界面和测试步骤可由 Zcode 操作，但敏感凭据、安全桌面及真实锁屏/解锁不应由 Zcode读取密码或伪造人工证据。

建议执行方式：

1. Zcode 负责构建、安装、普通 UI 操作、临时账户准备、日志与截图收集。
2. 遇到登录密码、私钥密码、SmartScreen/UAC 安全桌面和 `Win+L` 解锁时暂停。
3. 你本人完成敏感交互后，Zcode继续验证并记录不含秘密的结果。
4. 无法由人工实际完成的项目必须标记 `PENDING`，不得写成 `PASS`。

## 唯一确认问题

是否采用上述“Zcode 执行并取证，敏感交互和真实锁屏/解锁由你本人完成”的混合验收方式？

推荐：**采用。它既能让 Zcode完成绝大多数工作，又不会把密码、私钥或伪造的人工验收当作发布证据。**

## 用户决定

- 决定：**采用混合验收方式**。
- Zcode：负责构建、安装、普通 UI 操作、临时账户准备以及非敏感日志和截图取证。
- 用户：负责输入密码、处理私钥、确认 SmartScreen/UAC 安全桌面以及真实执行 `Win+L` 锁定和解锁。
- 证据规则：未被实际观察和验证的项目保持 `PENDING` 或 `BLOCKED`，不得标记为 `PASS`。
