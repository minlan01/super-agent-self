## 2. 已实现内容

### 2.1 Isolation broker

主要文件：

- `packages/platform/windows/isolation.py`

已实现：

1. 修复 `ctypes.wintypes.LUID_AND_ATTRIBUTES` 不存在导致的初始化失败。
2. 使用 pywin32 创建并验证 primary restricted token。
3. 为每个 broker 创建唯一 AppContainer profile 和 Package SID。
4. 默认使用零 capability，空网络 allowlist 由 AppContainer 默认拒绝。
5. 非空网络 allowlist 在任何原生副作用前 fail-closed。
6. workspace、runtime roots 和既有子树执行 ACL 预快照。
7. workspace 给 Package SID `RWX/DELETE`，runtime roots 只给 `RX`。
8. 拒绝 reparse point、workspace/runtime/deny path 重叠和不安全路径。
9. 使用原始安全描述符恢复 ACL，保留原 DACL 控制位。
10. 初始化失败和 `close()` 均执行 profile、SID、token、ACL、secret 的清理。

### 2.2 Process sandbox

主要文件：

- `packages/platform/windows/process_sandbox.py`

生产启动顺序：

```text
CreateProcessAsUserW(
  restricted primary token,
  CREATE_SUSPENDED,
  PROC_THREAD_ATTRIBUTE_HANDLE_LIST,
  PROC_THREAD_ATTRIBUTE_SECURITY_CAPABILITIES
)
-> AssignProcessToJobObject
-> 验证 primary/restricted/AppContainer/Package SID
-> ResumeThread
```

任一创建、Job 分配或令牌校验失败时，suspended child 会被终止，不执行用户代码。

### 2.3 Task-scoped 生产装配

主要文件：

- `packages/platform/windows/sandbox_factory.py`
- `packages/platform/windows/process_tools.py`
