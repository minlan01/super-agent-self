# Windows GA 收尾手册评审问题 05

- 日期：2026 年 8 月 23 日
- 发布定位：Personal/Internal GA
- Updater：移至后续 P5，本次采用手工升级与回退

## 当前主机条件

- 系统：Windows 11 Pro，Build `26200`
- Hyper-V：已启用
- 虚拟化：可用
- 内存：约 `15.8 GB`
- C 盘可用：约 `60.5 GB`
- D 盘可用：约 `28.5 GB`
- 当前未发现已有 Hyper-V VM

资源足以**顺序**完成 Windows 11 和 Windows 10 22H2 干净系统验证，但不建议同时运行或长期保留两台完整 VM。

## 必需系统操作

干净矩阵需要允许 Zcode：

1. 创建和删除临时 Hyper-V VM/快照。
2. 创建和删除临时本地标准用户。
3. 临时断开 VM 网络，验证 WebView2 离线安装。
4. 在 VM 中安装、卸载应用并重启。
5. 保存截图、日志、系统版本和测试结果；不得保存账户密码。

## 唯一确认问题

是否授权 Zcode 执行上述临时 VM 和系统级验收操作？

推荐：**允许，但只操作明确命名的测试 VM/临时账户；创建前记录路径和磁盘大小，删除前再次核对绝对路径，禁止修改宿主机启动、安全和现有用户配置。**
