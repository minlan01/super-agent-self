# Windows GA 收尾手册评审问题 06

- 日期：2026 年 8 月 23 日
- 发布定位：Personal/Internal GA，仅本人使用

## 已核实情况

远端签名脚本会把自签代码签名证书创建在：

```text
Cert:\CurrentUser\My
```

这只保存证书和私钥，不会让 Windows 自动信任该发布者。微软官方说明，自签证书默认不受 Windows 信任，适用于开发、测试或内部场景；未手工建立信任时仍会出现 SmartScreen/未知发布者提示。

把自签证书额外导入 `Trusted Root Certification Authorities` 或 `Trusted Publishers` 属于持久信任变更，不能作为签名脚本的隐藏副作用。

## 唯一确认问题

本次是否允许 Zcode 把自签证书自动加入 Windows 受信任证书存储？

推荐：**不允许自动加入。Zcode 只完成签名、导出公钥证书、记录 SHA-256/证书指纹并验证文件未被篡改；你继续接受本机首次 SmartScreen 手工确认。若以后需要消除提示，再由你核对指纹后单独批准信任导入。**

## 用户决定

- 决定：**允许**。
- 安全边界：仅允许导入明确命名的临时测试 VM；不得修改宿主机的受信任根证书或受信任发布者存储。
- 清理要求：证书随临时 VM 删除；日志只记录公钥证书指纹、用途和导入/移除结果，不记录私钥或密码。
