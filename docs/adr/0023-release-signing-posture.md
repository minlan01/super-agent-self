# ADR-0023: v1.0 发布签名姿态 — 自签自用,预留对外升级路径

日期: 2026-08-23
状态: 已接受

## 决策

Windows v1.0 定位为**个人自托管工具**(作者本人使用),发布签名采用
**自签证书 + 公布 SHA-256 指纹**;不购买生产代码签名证书。
对外分发/推广时再升级为生产证书(优先 Certum 开源证书 ~€25-70/年,
需仓库转公开;备选 Azure Trusted Signing ~$10/月)。

## 背景

- Gate Record #4 原按对外商业软件标准要求生产 Authenticode 证书
- 实际用户=作者本人,SmartScreen 警告/杀软加白为一次性成本
- updater 体系使用独立 minisign 密钥对(Tauri signer),与
  Authenticode 无耦合,更新/回退链路不受本决策影响
- 可复现构建(CI digest 比对)、审计链、许可证扫描等其余 Gate 项
  与签名无关,照常执行

## 后果

**现在(自用)**:
- 安装时 SmartScreen 弹一次警告 → "仍要运行";杀软首次误报加白一次
- 篡改检测保留:自签验签 + 发布页公布安装器/主程序 SHA-256
- Gate #4 判定改为 "PASS (self-signed, 指纹已公布)" — 前提是指纹
  记录在 `docs/releases/RELEASES.md`

**将来(对外推广)触发条件**(满足任一即启动升级):
1. 出现第一位外部安装者
2. 计划公开宣传 / 上分发渠道
3. 企业/朋友要求部署

**升级动作**(全部预留好,零重构):
- `tools/release/sign_release.ps1` 已参数化:`-PfxPath/-Password`
  传正式证书即走生产签名,其余流程不变
- 仓库转公开(若走 Certum)只影响可见性,不影响构建
- updater 密钥/渠道/N-1 体系不变
- CI 可复现构建 digest 体系不变
- 仅需:买证书 → 换参数重签 → 重发 1.0.x → RELEASES.md 更新签名状态

## 回归点

- 若自签私钥丢失:指纹仍可核对完整性,但验签失效 → 重新自签重发
- 若未升级证书就对外分发:SmartScreen 信誉永不积累,推广期需
  提前 1-2 个月完成证书升级(OV 信誉积累期)
