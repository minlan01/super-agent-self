4. Production-sign and timestamp the desktop executable, every executable payload and the final installer.
5. Implement signed updater metadata, staged channels, interrupted-update recovery and N-1 atomic rollback.
6. Close the offline WebView2 path with an approved standalone runtime or an offline-capable installer bundle.
7. Execute clean Windows 11 standard-user, second-account isolation and clean Windows 10 22H2 matrices.
8. Reproduce the candidate on an isolated build host/CI runner from the same commit and lockfiles.
9. Add enforced Node/Rust license policy and retain an approved N-1 rollback package.
