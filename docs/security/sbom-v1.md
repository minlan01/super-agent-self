## 3. License Review

The Python product lock contains 72 entries and the license tool returned metadata for 71 distributions; `wcwidth` needs manual metadata review. No returned package is identified as AGPL-only or GPL-only. `text-unidecode 1.3` is dual-listed under Artistic License and GPL; distribution must explicitly rely on the Artistic License option and retain its notices.

Before GA, add equivalent machine-readable license reports for Node and Rust and make the release pipeline fail on disallowed licenses.

## 4. Reproducibility Controls

- Python versions are pinned in `requirements-win-locked.txt`.
- Node versions are pinned in `package-lock.json` and installed with `npm ci`.
- Rust versions are pinned in `Cargo.lock`.
- Windows MSVC links with `/Brepro` through `apps/desktop/src-tauri/.cargo/config.toml`.
- NSIS excludes source file timestamps through `nsis/reproducible-build.nsh`.

On 2026-08-16, two consecutive complete Tauri builds produced identical SHA-256 values for both the desktop executable and NSIS installer.

## 5. Remaining Supply-Chain Gates

- Production Authenticode certificate and trusted timestamp.
- Signing of all inner executable payloads before bundling.
- Signed updater manifest and channel metadata.
- Pin `cargo-cyclonedx` in CI and add Node/Rust license-policy enforcement.
- Clean, isolated build-host or CI reproduction rather than same-host reproduction only.
- Hashes for downloaded wheels and an offline dependency mirror manifest.
